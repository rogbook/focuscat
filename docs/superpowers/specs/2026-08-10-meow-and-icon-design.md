# 완료 야옹 소리 · 앱 아이콘 교체 (설계)

날짜: 2026-08-10

[사냥 애니메이션 설계](2026-08-10-cat-hunt-animation-design.md)에 이어지는 작업.

## 1. 집중이 끝나면 고양이가 운다

시간이 다 됐는데 폰을 안 보고 있으면 끝난 줄 모른다. 소리로 알린다.

- **성공했을 때만** 운다. 포기·이탈은 알림이 아니라 나무라는 소리가 된다.
- 결과 화면이 뜨는 순간 시작해서 **"야옹 … 야옹 …"** 반복한다.
- 멈추는 경우는 넷:
  1. 화면 아무 곳이나 누른다
  2. "돌아가기"를 눌러 화면을 떠난다
  3. 광고가 뜬다(3회마다) — 야옹과 광고 소리가 겹치면 최악이다
  4. **1분이 지난다** — 폰을 두고 자리를 비웠는데 하염없이 울면 배터리도 닳고 민폐다
- 집중 화면에서 **음소거를 켜 놨으면 울지 않는다.** 그 버튼을 넣은 이유가 "소리를 낼 수 없는 곳"이었다. 거기서 끌 때까지 울면 그 사람은 앱을 지운다. 음소거여도 덮치는 장면과 결과 화면은 보이므로 끝난 것은 알 수 있다.

### 만드는 법

- 소리 파일 `assets/meow.mp3` = **"야옹" 한 번 + 뒤에 1.5초 침묵.** 이걸 그냥
  반복 재생하면 "야옹 … 야옹 …"이 된다. **간격을 재는 코드가 필요 없다.**
  야옹을 두 번 넣으면 재촉하는 느낌이 나서 한 번만 넣는다.
- 재생기는 배경음에 이미 쓰는 `just_audio`. 새 의존성 없음.
- 소리는 힉스필드로 만든다(저작권이 깨끗하다).

### 코드

- `lib/focus_timer.dart`에 순수 함수 하나:
  `bool shouldMeow(FocusOutcome outcome, bool muted)`. 조건이 둘뿐이지만
  화면 밖으로 빼야 테스트할 수 있다.
- `ResultScreen`에 `muted` 인자를 더한다. 음소거 상태는 `FocusScreen`이 갖고
  있어서 넘겨주지 않으면 결과 화면이 알 수 없다.
- `_ResultScreenState`가 재생기와 1분 타이머를 들고, `dispose`에서 반드시
  정리한다. 배경음이 화면보다 오래 살아남았던 사고가 있었으므로
  `_musicDisposed`와 같은 방식으로 한 번만 dispose 한다.

## 2. 앱 아이콘 — 고양이를 키우고 뒤에 시계를 놓는다

지금 아이콘은 고양이가 너무 작아 홈 화면 크기에서 뭔지 안 보인다.

**고른 안: 흰 시계판 위의 큰 고양이.**

- 민트(`#50C2C9`) 바탕 → 흰 원판 → 어두운 눈금 12개(3·6·9·12시는 길게)
  → 그 위에 고양이
- 고양이 크기를 3배 가까이 키운다
- 흰 원판을 쓰는 이유: 작아져도 시계로 읽히고, 검은 고양이와 대비가 강해
  홈 화면 크기에서 형태가 살아난다. 눈금만 있는 안은 작아지면 "반짝임"으로
  보인다(실제로 76px로 줄여 비교했다).

### 만드는 법

- `tool/make_app_icon.py`가 두 파일을 만든다. 손으로 그리지 않는다.
- **고양이 원본은 `assets/icon/cat_art.png`로 따로 둔다.** 지금은 생성물인
  `app_icon_foreground.png`가 원본을 겸하고 있어서, 생성기를 두 번 돌리면
  자기 출력을 원본으로 읽어 그림이 망가진다.

| 파일 | 쓰임 | 시계판 반지름 | 고양이 높이 |
|---|---|---|---|
| `app_icon.png` | iOS·기본 (민트 배경 포함) | 400 | 470 |
| `app_icon_foreground.png` | 안드로이드 적응형 (배경 투명) | 330 | 390 |

안드로이드 적응형 아이콘은 **가운데 66%만 확실히 보인다**(바깥은 기기마다
잘린다). 그래서 전경용은 더 작게 그린다. 1024px 기준 반지름 341 안쪽.

- 각 크기 파일은 `dart run flutter_launcher_icons`가 생성한다.

## 확인 방법

- `test/focus_timer_test.dart`에 `shouldMeow` 경우 네 가지(성공·음소거 조합).
- 시뮬레이터: 1분 집중 → 완료 → 야옹이 반복되는지, 화면을 누르면 멈추는지,
  음소거를 켜고 하면 안 울리는지, 포기했을 때 안 울리는지.
- 아이콘: 홈 화면에서 실제 크기로 확인.

## 안 하는 것

- 진동 알림 (요청에 없다)
- 야옹 소리 고르기 화면 (설정이 늘면 관리가 늘어난다)
- 실패했을 때의 소리
