# Play 데이터 보안 · App Store 개인정보 답안지

앱이 실제로 하는 일 기준으로 채운 답입니다. 콘솔에서 그대로 고르시면 됩니다.
근거: 앱 자체는 아무것도 전송하지 않고([lib/app_state.dart](../lib/app_state.dart) —
집중 기록은 SharedPreferences에만 저장), 외부로 나가는 것은 Google AdMob 뿐입니다.

---

## Google Play — 데이터 보안 (Data safety)

### 첫 화면 질문

| 질문 | 답 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | **예** (광고 SDK 때문) |
| 전송 중 데이터가 암호화되나요? | **예** (Google 광고 요청은 HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **아니요** — 계정이 없고 기록이 기기에만 있어 삭제 요청 대상 데이터가 없음 |

### 수집 항목

**기기 또는 기타 ID (Device or other IDs)** — 유일하게 선택할 항목

| | |
|---|---|
| 수집됨 | 예 |
| 공유됨 | **예** (Google AdMob에 전달) |
| 처리 방식 | 일시적으로만 처리되지 않음 (지속 수집) |
| 필수 여부 | **선택 가능** — 사용자가 추적/맞춤 광고를 끌 수 있음 |
| 목적 | **광고 또는 마케팅** |

### 선택하지 **않는** 항목 (실제로 수집하지 않음)

- 이름 · 이메일 · 전화번호 · 주소 — 계정 자체가 없음
- 사진 · 동영상 · 파일 · 연락처 · 캘린더 — 권한 요청 안 함
- 정확한 위치 · 대략적인 위치 — 위치 권한을 요청하지 않음
  (AdMob이 IP로 국가 수준을 추정하지만, Play 기준으로는 앱이 위치를
  수집하는 것이 아니므로 선택하지 않습니다)
- 앱 활동 · 검색 기록 — 집중 기록은 기기 밖으로 나가지 않음
- 앱 성능 · 진단 · 크래시 로그 — 크래시 리포팅 SDK 없음

### 기타

- **광고 ID 사용 신고**: 예 (Play Console → 앱 콘텐츠 → 광고)
- **앱에 광고 포함**: 예
- **타겟층**: 만 13세 이상 (어린이 대상 아님)
- **개인정보처리방침 URL**: 아래 호스팅 후 입력

## App Store Connect — 앱 개인정보 (App Privacy)

### 데이터 수집 여부
**예, 이 앱에서 데이터를 수집합니다**

### 수집 항목: 식별자 → 기기 ID (Identifiers → Device ID)

| | |
|---|---|
| 사용 목적 | **서드파티 광고** |
| 사용자 신원과 연결됨 | **아니요** |
| 사용자 추적에 사용됨 | **예** — 그래서 ATT 동의를 요청합니다 |

### 사용 데이터 → 광고 데이터 (Usage Data → Advertising Data)

| | |
|---|---|
| 사용 목적 | 서드파티 광고 |
| 사용자 신원과 연결됨 | 아니요 |
| 사용자 추적에 사용됨 | 예 |

> ATT 동의를 요청하는 앱은 "추적에 사용됨"을 반드시 **예**로 답해야 합니다.
> 아니요로 답하면서 ATT를 띄우면 심사에서 반려됩니다.
